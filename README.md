# Personal Profile Page

This is a simple personal profile page created as part of a mini project to practice basic HTML structure and tags.

## Project Description
The project demonstrates the use of core HTML elements by creating a personal profile page that includes a name, short bio, image, and contact form.  
Basic CSS styling and JavaScript were added as optional bonus features.

## Features
- Heading with full name
- Profile image
- Short bio paragraph
- Contact form:
  - Name input
  - Email input
  - Message textarea
  - Submit button
- Dark blue themed design using CSS (bonus)
- Simple JavaScript alert on form submission (bonus)

## Technologies Used
- HTML
- CSS
- JavaScript
